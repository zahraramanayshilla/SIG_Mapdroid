Fitur Unggulan SIG Mapdroid

Dirancang untuk memberikan kemudahan eksplorasi data geospasial pada lingkungan akademik dan lapangan.

Engine MapLibre Native

Rendering peta vektor dan raster dengan akselerasi hardware OpenGL/Vulkan, menjamin pergerakan peta 60 FPS mulus dan hemat konsumsi daya baterai.

Pelacakan GPS Presisi

Terhubung langsung dengan sensor GPS perangkat mobile Android Anda untuk mendeteksi posisi secara tepat, lengkap dengan mode kompas orientasi arah.

Visualisasi GeoJSON Lengkap

Mendukung layer spasial poligon (gedung kampus), garis jalur (jalan penghubung), dan titik fasilitas POI dengan atribut kustom yang dapat diperiksa.

CI/CD Auto Release

Setiap perubahan kode yang di-push ke branch utama akan otomatis di-build oleh GitHub Actions, dibuatkan tag rilis semantik baru, dan APK siap diunduh seketika.

Integrasi CrootJS Dinamis

Landing page menggunakan modul mikro CrootJS (jscroot) untuk mengambil status dan URL unduhan rilis APK terbaru secara langsung dari GitHub API tanpa ketergantungan berat.

Bebas Lisensi & Offline Friendly

100% open source tanpa kewajiban token berbayar komersial. Data spasial aset lokal disematkan langsung di dalam berkas instalasi APK.

Panduan Langkah Demi Langkah

Cara Mengunduh, Memasang & Menggunakan Aplikasi

Ikuti petunjuk praktis berikut untuk memasang file APK pada smartphone Android Anda.

1

Panduan Instalasi APK Android

  1. A
    Unduh Berkas APK:

    Klik tombol "Unduh APK Terbaru" pada halaman ini atau buka tab Releases di repositori GitHub.

  2. B
    Buka Berkas APK:

    Setelah pengunduhan selesai, buka berkas melalui notifikasi download atau melalui aplikasi File Manager di folder Download.

  3. C
    Izinkan Sumber Tidak Dikenal:

    Jika muncul peringatan keamanan sistem Android, pilih Setelan (Settings) lalu centang/aktifkan "Izinkan dari sumber ini" (Install unknown apps).

  4. D
    Pasang & Buka Aplikasi:

    Tekan tombol Instal (Install) dan tunggu beberapa saat hingga muncul notifikasi "Aplikasi terpasang". Tekan Buka (Open).

  5. E
    Izinkan Hak Akses Lokasi (GPS):

    Saat aplikasi meminta izin lokasi, pilih "Saat aplikasi digunakan" (While using the app) agar fitur pelacakan rute berfungsi.

2

Panduan Fitur Aplikasi Mobile

Navigasi Gestur Layar Sentuh

Gunakan 1 jari untuk menggeser posisi peta, 2 jari cubit (pinch) untuk zoom in/out, 2 jari putar untuk mengubah orientasi kompas, dan 2 jari geser ke atas untuk melihat kemiringan 3D.

Tombol Pelacakan GPS (Lingkaran Biru)

Tekan tombol GPS di pojok kanan bawah layar untuk mengarahkan kamera langsung ke posisi koordinat fisik Anda saat ini.

Pemeriksaan Atribut Spasial Objek

Sentuh salah satu poligon gedung (misal Gedung Pos, Rektorat, atau Vokasi) untuk memunculkan kartu informasi nama gedung dan koordinat geografisnya.

Ganti Tampilan Basemap

Tekan tombol tumpukan layer di atas tombol GPS untuk berganti antara mode peta OpenStreetMap standard dan peta vektor kontur.
